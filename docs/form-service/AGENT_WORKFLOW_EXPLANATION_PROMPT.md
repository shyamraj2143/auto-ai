# Code explanation prompt

इस repository के AutoAI Seva agent workflow को source code के आधार पर समझाओ। खास तौर पर ये files पढ़ो: `backend/app/models/autoai_seva.py`, `backend/app/services/seva_assignment.py`, `backend/app/api/routes/seva_operations.py`, `backend/app/api/routes/seva_scope.py`, `frontend/src/features/autoaiSeva/SevaOperationsPage.tsx`, `frontend/src/features/autoaiSeva/SevaAssistancePanel.tsx`, `frontend/src/components/auth/AgentLoginPage.tsx`, और `frontend/src/App.tsx`।

उत्तर में flow को इस क्रम में बताओ: AI Chat/Seva request → dynamic form और document collection → user consent → work-order creation → capacity-aware least-loaded agent assignment/FIFO queue → separate agent login → assigned task workspace → non-secret information/document request → protected OTP/password/CAPTCHA user action → status/notification updates → final receipt/deliverable। हर चरण के backend endpoint, persisted model, authorization rule और frontend component का नाम बताओ। साफ बताओ कि raw OTP/password/CAPTCHA/PIN/CVV/token कभी chat, database, logs, notification या agent view में नहीं जाते और unsupported portal submission को success नहीं कहा जाता। अंत में local verification commands और production deployment checklist दो। केवल repository में मौजूद implementation explain करो; काल्पनिक capability न जोड़ो।
